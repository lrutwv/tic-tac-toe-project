# Tic Tac Toe — Solo or Duo!

A simple **Tic Tac Toe** game where you can play against another player or challenge the computer.

The project has a calm **tropical / Lovers Rock-inspired theme**, with dark green colors and a sunset/island feeling. 

## Features

* 2 Player mode
* 1 Player vs Computer mode
* Player name customization
* 3 Points or 5 Points match
* Score tracking
* Winning-cell glitch effect
* Responsive layout
* Play Again and Reset Game options

## 📚 What I Learned

While making this project, I practiced:

* HTML structure
* CSS styling and responsive design
* JavaScript game logic
* DOM manipulation
* Event listeners
* Functions and conditional statements
* Keeping track of game scores and turns

## 🚧 Work in Progress

This project is **not completely finished yet**.

The background, fonts, avatars, and some of the visual details are still being worked on. For now, this is the current version of the game while I continue improving the design and overall theme.
